1. 프로그램 소개

Insta-Card Studio는 스마트폰과 PC 브라우저에서 누구나 쉽고 빠르게 고화질 템플릿 이미지를 제작할 수 있는 모바일 웹 앱입니다.

• 무엇인가요? 다양한 디자인 프레임(12종), custom 폰트, 문구를 조합하여 SNS 카드 뉴스, 감성 폴라로이드, 미니멀 포스터를 완성하는 그래픽 제작 도구입니다.
• 누구에게 필요한가요? 인스타그램/블로그 운영자, 여행·일상 기록을 특별하게 담고 싶은 분, 디자이너 프로그램 없이 빠르게 감성 이미지를 만들고 싶은 분에게 필수적입니다.

2. 접속 및 PWA 설치 방법

상단 헤더의 '앱 설치' 버튼을 클릭하면 한 번에 스마트폰 홈 화면에 앱을 추가할 수 있습니다.

  • 원클릭 설치: 헤더 상단의 [앱 설치] 버튼 클릭 후 설치 수락
  • iOS (사파리): 하단 공유 버튼() ➔ '홈 화면에 추가'
  • Android (크롬): 우측 상단 메뉴() ➔ '앱 설치' 또는 '홈 화면에 추가'

3. 화면 구성 및 버튼 설명

🖼️ 실시간 미리보기 (Canvas)

선택한 사진, 프레임, 폰트, 색상이 실시간으로 합성되는 영역입니다.

📸 앨범 선택 & 카메라 촬영 버튼

사진을 업로드하거나 현장에서 즉시 촬영합니다.

🎞️ 템플릿 가로 스크롤 바

12가지 프레임을 좌우로 스크롤하여 변경합니다.

4. 기능별 단계별 사용 방법

기능 1. 사진 불러오기

  1. '앨범에서 선택' 또는 '카메라 촬영' 버튼을 누릅니다.
  2. 원하는 이미지 파일 선택 또는 촬영 후 완료를 클릭합니다.

기능 2. 프레임 & 폰트 스타일 꾸미기

  1. 프레임 템플릿 목록을 옆으로 스크롤하여 원하는 스타일을 선택합니다.
  2. 글꼴 선택 메뉴와 색상 선택 버튼으로 텍스트 스타일을 변경합니다.

기능 3. 결과물 저장 및 모바일 공유

  1. '고화질 이미지 저장'을 눌러 PNG로 다운로드합니다.
  2. '모바일 직접 공유'를 눌러 SNS에 즉시 전송합니다.
